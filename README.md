# CPE447 Game — คดีฆาตกรรมต่อเนื่องแห่งไวท์ชาเปล

เกมสืบสวนบุคคลที่สามในลอนดอนยุควิกตอเรีย ผู้เล่นรับบทสารวัตรนิวแมน ตามรอยคดีฆาตกรรมต่อเนื่องผ่าน 4 สถานที่
และใช้ระบบตรวจพิสูจน์หลักฐานด้วย Computer Vision (CiRA CORE) สแกนวัตถุพยานในที่เกิดเหตุ

## เนื้อเรื่องแต่ละฉาก

| ฉาก | สถานที่ | หลักฐานที่สแกน |
|---|---|---|
| 1 | โบสถ์เซนต์แมรี่ | รอยเท้า, ผ้าเช็ดหน้า, กระดาษบทสวด, แหวนวงใหญ่, แหวนวงเล็ก |
| 2 | ตรอกในลอนดอน | กระดุมเสื้อ, ตั๋วละคร, รอยเท้า, มีดพก, หนังสือพิมพ์ |
| 3 | โรงละครรอยัลไลเซียม | ตั๋วละคร, หน้ากาก, ไม้เท้า, เศษผ้า, จดหมาย |
| 4 | สถานีรถไฟใต้ดิน | ตั๋วรถไฟ, ปลอกกระสุน, นาฬิกาพก, รอยเลือด, จดหมาย |

เมื่อสแกนครบ ผู้เล่นต้องเชื่อมโยงหลักฐานบนกระดานอนุมานเพื่อไขปริศนาและปลดล็อกฉากถัดไป

## ระบบตรวจพิสูจน์หลักฐาน (CiRA CORE)

- แต่ละฉากมีโมเดลตรวจจับวัตถุของตัวเอง อยู่ใน `Assets/CiraCore/` (ไฟล์ `obj.names`, `train.weights`, cfg)
- ระบบจะสลับโมเดลให้อัตโนมัติเมื่อเริ่มเควสของฉากนั้น
- เล็งวัตถุค้างไว้เพื่อสแกน กรอบจะแสดงชื่อคลาสและค่าความมั่นใจ แล้วบันทึกลงแฟ้มคดี

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| WASD | เดิน |
| เมาส์ | หมุนกล้อง |
| คลิกขวา / V / Tab / F | เปิด–ปิดโหมดสแกนหลักฐาน |

## การเปิดโปรเจกต์

1. ติดตั้ง [Git LFS](https://git-lfs.com) ก่อน clone (โมเดลเมือง `London.fbx` เก็บผ่าน LFS)
   ```
   git lfs install
   git clone https://github.com/BANK123JULLAJAK/CPE447_Project.git
   ```
2. เปิดด้วย Unity **6000.5.0f1** (Universal Render Pipeline)
3. เปิดฉาก `Assets/Scenes/SampleScene.unity` แล้วกด Play

ครั้งแรกที่เปิด Unity จะ import asset ทั้งหมดใหม่ อาจใช้เวลาหลายนาที
